# Photography

Generated by `scripts/build-media.mjs`. Do not edit these files by hand and do
not add anything here that the script did not produce — Caddy serves this
directory with `immutable` caching for a year, which is only safe because every
filename carries a content hash.

To change or add a photograph, put the source in a directory and run:

    node scripts/build-media.mjs <source-directory>

## Two rules about how these are used

**None of them contain people, deliberately.** Two further photographs were
supplied showing recognisable people and were left out. A stock photograph of
strangers on this site is read by visitors as our team or our clients, and
Charter 04 §IV forbids anything untrue on a Genmars surface. Alt text describes
what is in the frame and never claims it is us.

**None of them appear on `/work`.** That page describes real client projects.
Stock imagery there would not be decoration, it would be a false impression of
work we did.
